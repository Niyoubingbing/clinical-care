# 2.18.1 发布补丁

在 2.18.0 的正式环境验收中，发现“虚拟床”标签在字体加载完成后的文字对比度仅约 4.4:1，略低于 AA 标准。改为有充分对比余量的浅色/深色标签组合，并在浏览器测试中等待字体加载、检查两个主题下的标签。

本版本包含 [2.18.0](./RELEASE-2.18.0.md) 的全部床号识别、查房顺序、导入及离线修复；不改变业务数据和配置。

风险：L1 视觉修复。版本提升到 2.18.1，使 PWA 使用独立版本缓存，避免同版本重新部署造成缓存混用。

回滚边界与 2.18.0 相同；此补丁不新增迁移。发布后核对 GitHub main、CI、Vercel READY、正式域名版本与真实断网操作。
