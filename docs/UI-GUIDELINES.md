# 界面规范（当前实现）

本文是临床护理 PWA 的当前页面标准。以代码实际实现为准；新增或重做页面时，应先遵循本规范，再在 PR 中说明例外原因。

## 页面层级

### 设置首页

固定采用：页面眉标与标题 → 一句用途说明 → 分组标题与说明 → 卡片列表/操作卡片 → 维护与版本信息。

### 设置子页

固定采用：`SubpageHeader`（返回、标题、描述、可选主操作）→ 页面级操作/模式切换 → `subpage-section-heading`（区块标题、说明、数量）→ 列表或编辑卡片 → 次要导入导出操作。

不要在同一页面混用多个同级大标题；同一组内容优先使用一个卡片容器和分隔线，而不是连续堆叠独立阴影卡片。

## 视觉标准

- 以 390px 移动端宽度为首要验收尺寸，同时检查 768px 和桌面宽度。
- 页面左右留白保持一致；内容区不应产生横向滚动。
- 页面标题使用 20–24px，区块标题使用 15px，辅助说明使用 12px。
- 主操作使用 `btn-primary`，次要操作使用 `btn-secondary`；危险操作必须使用 `text-danger` 或危险背景。
- 列表行最小高度 48px，触控目标不低于 40px；拖拽、删除等图标按钮必须有 `aria-label`。
- 状态颜色必须同时有文字或图标含义，不能只靠颜色区分。

## 复用组件

- `SubpageHeader`：所有设置子页统一使用，不要自行复制返回按钮和标题布局。
- `settings-row` / `settings-list`：设置首页的导航和维护项。
- `subpage-section-heading`：子页列表、编辑区、汇总区的标题与数量提示。
- `card`：承载一组相关内容；避免一个字段一个卡片。

## 提交前检查

1. 页面是否能在 390px 宽度下完整操作，且没有横向溢出？
2. 是否只有一个页面主标题，区块标题层级是否连续？
3. 是否复用了已有组件和语义化按钮，而不是复制一套新样式？
4. 空状态、加载状态、错误状态是否都有明确文案？
5. 键盘焦点、按钮标签、颜色对比度是否可读？
6. 页面行为变化后，是否同步更新 PRD、测试或审查记录？
