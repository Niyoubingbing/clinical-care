| 文档 | 用途 | 更新触发 |

| [PRD](../PRD.md) | 当前用户行为、规则和边界 | 功能或验收口径变化 |

| [OPERATIONS](./OPERATIONS.md) | 开发、部署、验证、回滚和故障处理 | GitHub/Vercel/令牌/运行手册变化 |
