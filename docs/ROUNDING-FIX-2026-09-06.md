# 查房排序与加床修复

基线为 GitHub 2.17.3；保留已确认的换药规则入口与紧凑筛选条，没有整体界面重构。仅本地修改，未发布。

## 统一识别和排序

`lib/rounding-match.ts` 是床型、查房排序、床号识别页归属展示的共同匹配来源。

| 配置床号 | 行为 |
| --- | --- |
| 普通病房块 `01` | 对各病区的普通 01 床套用，不误匹配 J01 / YZ01；同基础床的子床均入列 |
| 加床块 `J04` / `YZ04` | 保留加床字母标记，在各病区匹配相应加床 |
| 完整床号 `309WJ04` | 精确匹配；不改变其他条目的匹配方式；也支持完整自定义床号 |
| 加床块纯数字 `04` | 兼容旧配置，仅匹配带字母标记的同号床，不占用普通 04 床；有多种加床标记时建议写明 `J04` 或 `YZ04` |

明确的完整床号指定优先于相对模板。同样精确度的重复规则由前面的块优先接收；每位病人只入列一次。混合配置中，有相对床号时按病区逐一套用完整块序列；全是完整床号时保留显式跨病区块顺序。未匹配的病人稳定追加到末尾，不删除病人。

强制虚拟名单仍具有最高床型优先级，不会在修复时擅自清空。在床号识别页重新加入某床，会解除该床的强制虚拟标记。

## 调整与保存

- 块可拖动或用上下按钮移动，房内床位可前移、后移。
- 新增及导入保留输入顺序，不再自动升序覆盖手动安排。
- 普通块中填写完整床号不再被 `parseInt` 截成前缀数字；块内重复床号不重复添加。
- 切换到基础规则只打开设置，不清空现有块。重新生成、恢复默认前明确确认覆盖范围。
- 规则修改显示“保存中／已保存／失败”；连续操作串行保存，不并发覆盖。
- `saveRoundingConfig` 在事务中检查配置基线，其他页面或标签页已修改时拒绝旧快照覆盖并提示重新载入。
- 床号识别页使用相同归属函数。移出一个被基础模板覆盖的病人时，仅对其完整床号设置虚拟覆盖，不删除其他病区共用的基础模板；重新加入可正常解除覆盖。
